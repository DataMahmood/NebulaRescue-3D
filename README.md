# 🚀 Nebula Rescue 3D

**Nebula Rescue 3D** is a 3D space shooter for Android, built around fast arcade combat, enemy encounters, boss battles, power-ups, and resource management.

## 🎮 Features

- 3D space combat
- Multiple enemy types
- Boss battles with health mechanics
- Weapon overheating system
- Power-ups
- Background music controls
- Android-optimized gameplay

## 📱 Latest Android Release

**Version: v3.1.0**

Download the APK from the project's GitHub Releases page.

### Installation

1. Download the latest `.apk` from **Releases**.
2. Enable installation of apps from your browser/file manager if Android asks.
3. Install the APK.
4. Launch **Nebula Rescue 3D**.
